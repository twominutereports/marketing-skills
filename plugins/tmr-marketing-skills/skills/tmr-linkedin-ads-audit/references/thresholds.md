# LinkedIn Ads Scoring Thresholds

LinkedIn Ads operates in a B2B context with higher CPCs and longer buying cycles than most platforms. Use these benchmarks when scoring each module.

---

## Platform Context

LinkedIn CPCs are inherently higher ($5–$15+ average) due to premium professional targeting. Adjust expectations accordingly — a $20 CPC is not automatically wasteful if targeting senior decision-makers.

---

## Module 2: Wasted Spend Analysis (Score /20)

| Signal | Flag | Score Impact |
|---|---|---|
| Campaign with spend > $200 and 0 conversions (lead gen objective) | 🔴 | -4 |
| Campaign with spend > $500 and 0 conversions (awareness objective) | 🔴 | -3 |
| CTR < 0.30% on Sponsored Content | 🔴 | -2 |
| CTR < 0.15% on Message Ads | 🔴 | -2 |
| Frequency > 4 on same creative in 30 days | 🟡 | -2 |
| CPC > 3× account average | 🔴 | -3 |
| Campaigns still accruing spend with paused status | 🔴 | -4 |
| CPL > 3× account average with >10% budget share | 🔴 | -3 |

**Score 18–20**: Minimal waste, tight budget control
**Score 14–17**: Some inefficiency — addressable in 2–4 weeks
**Score 10–13**: Meaningful waste — needs immediate attention
**Score <10**: Significant structural problems

## Module 3: Campaign Performance Ranking (Score /20)

| Signal | Flag | Score Impact |
|---|---|---|
| CTR ≥ 0.60% (Sponsored Content) | 🟢 Scale | +3 |
| CTR 0.30%–0.59% | 🟡 Monitor | 0 |
| CTR < 0.30% | 🔴 Fix/Pause | -3 |
| CPL ≤ account avg | 🟢 | +3 |
| CPL 1–1.5× account avg | 🟡 | 0 |
| CPL > 2× account avg with >10% spend | 🔴 | -3 |
| Lead form completion rate ≥ 10% | 🟢 | +2 |
| Lead form completion rate < 5% | 🔴 | -2 |

## Module 4: Creative Audit (Score /20)

| Signal | Flag | Score Impact |
|---|---|---|
| ≥ 3 active creatives per campaign | 🟢 | +3 |
| Only 1 creative per campaign | 🔴 | -3 |
| Top creative CTR ≥ 2× bottom creative | 🟡 Creative fatigue signal | -2 |
| Single ad format used across all campaigns | 🟡 | -2 |
| Video completion rate < 25% | 🟡 | -2 |
| Document ad engagement rate ≥ 5% | 🟢 | +2 |

## Module 5: Audience & Budget Allocation (Score /20)

| Signal | Flag | Score Impact |
|---|---|---|
| >80% spend in one campaign | 🟡 Concentration risk | -2 |
| Audience size < 50,000 (too narrow) | 🟡 | -2 |
| Audience size > 5M (too broad for B2B) | 🟡 | -2 |
| Overlapping audiences across campaigns (>40% overlap) | 🔴 | -3 |
| Profitable campaign budget-limited | 🟢 Opportunity | +2 |
| Seniority/job title targeting without company size filter | 🟡 | -1 |
| Retargeting campaigns present | 🟢 | +2 |

## LinkedIn Benchmark Reference (B2B, general)

| Metric | Strong | Average | Weak |
|---|---|---|---|
| CTR (Sponsored Content) | ≥ 0.60% | 0.30–0.59% | < 0.30% |
| CTR (Message Ads) | ≥ 0.20% | 0.10–0.19% | < 0.10% |
| CPC | < $8 | $8–$15 | > $15 |
| CPL | Platform/industry varies — compare vs account avg | | |
| Lead form open rate | ≥ 15% | 8–14% | < 8% |
| Lead form completion rate | ≥ 12% | 6–11% | < 6% |
| Frequency (30d) | 1.5–3× | 3–4× | > 4× |
| Video completion rate | ≥ 50% | 25–49% | < 25% |
