# Website Traffic Growth Analyst — Claude Skill

A Claude skill that acts as your personal SEO specialist. Connect it to your website data and get a full traffic analysis, problem diagnosis, and 30-day action plan — automatically.

## Requirements & Setup

**Prerequisites**

- Claude.ai Pro, Team, or Enterprise account
- [Two Minute Reports](https://twominutereports.com) MCP connected in Claude Settings
- The relevant data source (Google Analytics, Search Console, etc.) linked within Two Minute Reports

**Installing a skill in Claude**

1. Download the `.md` skill file from the skill's folder in this repository
2. Go to [claude.ai/customize/skills](https://claude.ai/customize/skills)
3. Click the **+** icon → **Create skill** → **Upload a skill**
4. Select the downloaded `skill.md` file
5. Start chatting — each skill's README lists the trigger phrases you can use

## Usage

Just say: `Analyse my website` or `Check my SEO`

Claude will pull your data and deliver the full analysis automatically — no setup questions.

## What It Covers

| Section                 | What You Get                                |
| ----------------------- | ------------------------------------------- |
| Traffic Overview        | Growth trends and source breakdown          |
| CTR Problem Detector    | Low-click pages with rewrite suggestions    |
| Traffic Drop Diagnosis  | What dropped and how to recover             |
| Content Gap Finder      | New content ideas based on your traffic     |
| Keyword Cannibalization | Pages competing against each other          |
| Technical Health Check  | Indexing, crawl errors, mobile issues       |
| Engagement Insights     | Bounce rate, time on page, device breakdown |
| On-Page SEO Audit       | Title, meta, content quality fixes          |
| 30-Day Action Plan      | Week-by-week prioritised tasks              |
