# Local SEO Auditor — Claude Skill

A Claude skill that acts as your senior Local SEO consultant. It combines three Google sources via Two Minute Reports — Google Business Profile (GMB), Search Console (GSC), and Analytics 4 (GA4) — into one unified audit that follows the local customer journey: get found → take an action → land on the site → convert. Delivered as an HTML report with a Local SEO health score and a prioritised action plan.

## Requirements & Setup

**Prerequisites**

- Claude.ai Pro, Team, or Enterprise account
- [Two Minute Reports](https://twominutereports.com) MCP connected in Claude Settings
- The relevant data source (Google Business Profile, Search Console, Analytics, etc.) linked within Two Minute Reports

**Installing a skill in Claude**

1. Download all files in the skill's folder from this repository (skill.md plus any queries.json and references/)
2. Go to [claude.ai/customize/skills](https://claude.ai/customize/skills)
3. Click the **+** icon → **Create skill** → **Upload a skill**
4. Select the downloaded `skill.md` file
5. Start chatting — each skill's README lists the trigger phrases you can use

## Usage

Just say: `Run a local SEO audit` or `Audit my Google Business Profile` or `Why am I not showing up on Google Maps`

Claude will pull your live GMB, GSC, and GA4 data for the same business and produce the full audit automatically — no file uploads or manual data entry.

## What It Covers

| Section | What You Get |
| --- | --- |
| Executive Summary | Combined KPI scorecard — profile viewers, calls, impressions, clicks, sessions, engagement, and form submissions with period-over-period deltas |
| Visibility (GMB) | How customers find the profile — Maps vs Search views and weekly view trends |
| Profile Actions (GMB) | Calls, website clicks, direction requests, and messages, broken down by action type |
| Organic Search (GSC) | Impressions, clicks, CTR, average position, plus top queries and pages |
| Website & Conversion (GA4) | Sessions, engagement rate, key events, channel mix, and top landing pages |
| Reviews (GMB) | Total review count and average star rating |
| Prioritised Action Plan | Ranked fixes ordered by impact across the full found → action → site → convert journey |
