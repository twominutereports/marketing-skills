# Facebook Insights Reporter — Claude Skill

A Claude skill that acts as your senior organic social-media strategist. Connect it to your Facebook Page via Two Minute Reports and get a full organic performance report across Page growth, reach, engagement, posts, and videos/Reels — delivered as a rich HTML report with visual scorecards, a growth trend chart, and a prioritised action plan. (For paid Facebook/Meta ad campaigns, use the Meta Ads Auditor instead.)

## Requirements & Setup

**Prerequisites**

- Claude.ai Pro, Team, or Enterprise account
- [Two Minute Reports](https://twominutereports.com) MCP connected in Claude Settings
- The relevant data source (Facebook Insights, etc.) linked within Two Minute Reports

**Installing a skill in Claude**

1. Download all files in the skill's folder from this repository (skill.md plus any queries.json and references/)
2. Go to [claude.ai/customize/skills](https://claude.ai/customize/skills)
3. Click the **+** icon → **Create skill** → **Upload a skill**
4. Select the downloaded `skill.md` file
5. Start chatting — each skill's README lists the trigger phrases you can use

## Usage

Just say: `Audit my Facebook Page` or `Facebook Page performance report` or `Which Facebook posts perform best`

Claude will pull your live Facebook Page Insights data and deliver the full report automatically — no file uploads or manual data entry.

## What It Covers

| Section | What You Get |
| --- | --- |
| Executive Summary | Followers, organic impressions, page views, net growth, and post-engagement snapshot with period-over-period deltas |
| Growth & Engagement Trend | Weekly follows, unfollows, post engagements, organic impressions, and page views charted over the period |
| Engagement & Reactions | Post engagements relative to organic impressions, plus the full reactions breakdown (like, love, wow, haha, etc.) |
| Post Performance | Top posts ranked by reactions, with shares, comments, clicks, and format breakdown |
| Video / Reels Performance | Video views, completion, Reels plays, shares, comments, and average watch time |
| Audience Breakdown | Top countries and cities by organic impressions (current snapshot) |
| Prioritised Action Plan | Ranked, tiered next steps ordered by impact — the highest-leverage changes first |
