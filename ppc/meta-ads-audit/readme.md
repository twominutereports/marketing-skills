# Meta Ads Auditor — Claude Skill

A Claude skill that acts as your senior Meta Ads performance consultant. Connect it to your Facebook Ads account via Two Minute Reports and get a full audit across campaigns, ad sets, creatives, audiences, and placements — including creative fatigue signals — delivered as a scored HTML report with a prioritised action plan.

## Requirements & Setup

**Prerequisites**

- Claude.ai Pro, Team, or Enterprise account
- [Two Minute Reports](https://twominutereports.com) MCP connected in Claude Settings
- The relevant data source (Facebook Ads, etc.) linked within Two Minute Reports

**Installing a skill in Claude**

1. Download the `.md` skill file from the skill's folder in this repository
2. Go to [claude.ai/customize/skills](https://claude.ai/customize/skills)
3. Click the **+** icon → **Create skill** → **Upload a skill**
4. Select the downloaded `skill.md` file
5. Start chatting — each skill's README lists the trigger phrases you can use

## Usage

Just say: `Audit my Meta Ads` or `Review my Facebook campaigns` or `Check for creative fatigue`

Claude will pull your live Meta Ads data and deliver the full audit automatically — no file uploads or manual data entry.

## What It Covers

| Section                      | What You Get                                                                            |
| ---------------------------- | --------------------------------------------------------------------------------------- |
| Executive Summary            | Spend, impressions, clicks, CTR, CPC, conversions, CPA, and ROAS snapshot               |
| Wasted Spend Analysis        | Budget going to underperforming campaigns, ad sets, and audiences                       |
| Campaign Performance Ranking | All campaigns ranked by ROAS, CPA, and conversion volume                                |
| Ad Set Performance Audit     | Which ad sets are delivering and which are cannibalising budget                         |
| Creative Performance Audit   | Top and bottom creatives by CTR, conversion rate, and cost per result                   |
| Creative Fatigue Detection   | Creatives with declining frequency-adjusted performance and suggested rotation timing   |
| Audience Performance Audit   | Breakdown of performance by audience type — retargeting, lookalike, interest, and broad |
| Placement Performance Audit  | Feed vs Reels vs Stories vs Audience Network — where your spend is working hardest      |
| Prioritised Action Plan      | Ranked fixes ordered by impact — the highest-leverage changes first                     |
