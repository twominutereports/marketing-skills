# Google Ads Auditor — Claude Skill

A Claude skill that acts as your senior Google Ads performance consultant. Connect it to your Google Ads account via Two Minute Reports and get a full audit across campaigns, keywords, search terms, budget allocation, and wasted spend — delivered as a scored HTML report with a prioritised action plan.

## Requirements & Setup

**Prerequisites**

- Claude.ai Pro, Team, or Enterprise account
- [Two Minute Reports](https://twominutereports.com) MCP connected in Claude Settings
- The relevant data source (Google Ads, etc.) linked within Two Minute Reports

**Installing a skill in Claude**

1. Download all files in the skill's folder from this repository (skill.md plus any queries.json and references/)
2. Go to [claude.ai/customize/skills](https://claude.ai/customize/skills)
3. Click the **+** icon → **Create skill** → **Upload a skill**
4. Select the downloaded `skill.md` file
5. Start chatting — each skill's README lists the trigger phrases you can use

## Usage

Just say: `Audit my Google Ads` or `Review my Google Ads account` or `Find wasted spend in Google Ads`

Claude will pull your live Google Ads data and deliver the full audit automatically — no file uploads or manual data entry.

## What It Covers

| Section                      | What You Get                                                                                    |
| ---------------------------- | ----------------------------------------------------------------------------------------------- |
| Executive Summary            | Spend, clicks, impressions, CTR, CPC, conversions, CPA, and ROAS snapshot                       |
| Wasted Spend Analysis        | Budget being consumed by low-quality traffic, irrelevant queries, and underperforming campaigns |
| Campaign Performance Ranking | All campaigns ranked by ROAS, CPA, and conversion volume                                        |
| Budget Allocation Audit      | Whether spend is weighted toward your best-performing campaigns and where it's misallocated     |
| Keyword Audit                | Top and bottom keywords by CPA and ROAS, including quality score issues                         |
| Search Terms Audit           | Irrelevant search terms triggering spend and negative keyword opportunities                     |
| Prioritised Action Plan      | Ranked fixes ordered by impact — the highest-leverage changes first                             |
