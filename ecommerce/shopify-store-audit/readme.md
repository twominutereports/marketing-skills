# Shopify Store Auditor — Claude Skill

A Claude skill that acts as your senior ecommerce CRO consultant. Connect it to your Shopify store via Two Minute Reports and get a full audit across your conversion funnel, checkout friction, product performance, traffic sources, and cart abandonment — delivered as a scored HTML report with a prioritised action plan.

## Requirements & Setup

**Prerequisites**

- Claude.ai Pro, Team, or Enterprise account
- [Two Minute Reports](https://twominutereports.com) MCP connected in Claude Settings
- The relevant data source (Shopify, etc.) linked within Two Minute Reports

**Installing a skill in Claude**

1. Download the `.md` skill file from the skill's folder in this repository
2. Go to [claude.ai/customize/skills](https://claude.ai/customize/skills)
3. Click the **+** icon → **Create skill** → **Upload a skill**
4. Select the downloaded `skill.md` file
5. Start chatting — each skill's README lists the trigger phrases you can use

## Usage

Just say: `Audit my Shopify store` or `Run a store health check` or `Find my revenue leaks`

Claude will pull your live Shopify data and deliver the full audit automatically — no file uploads or manual data entry.

## What It Covers

| Section                   | What You Get                                                            |
| ------------------------- | ----------------------------------------------------------------------- |
| Executive Summary         | Revenue, orders, conversion rate, AOV, and sessions snapshot            |
| Funnel Conversion Audit   | Where visitors drop off between landing, product, cart, and checkout    |
| Checkout Friction Audit   | Steps causing abandonment and where buyers leave the checkout flow      |
| Mobile Experience Audit   | Mobile vs desktop conversion gap and mobile-specific friction points    |
| Product Performance Audit | Top and bottom products by revenue, conversion rate, and return rate    |
| Traffic Source Audit      | Which channels drive sessions, revenue, and the highest-quality buyers  |
| Cart Abandonment Audit    | Abandonment rate, recovery rate, and top reasons carts are left behind  |
| Geographic & Device Audit | Revenue and conversion breakdown by country and device type             |
| Prioritised Action Plan   | Ranked fixes ordered by revenue impact — the highest-value levers first |
